# Quick Sort Iterativo

## Como testar

Para compilar e executar o projeto no **Linux/macOS**, abra um terminal no diretório do projeto e execute:

```bash
make main
./main
```

No **Windows**, utilizando MinGW, execute:

```bash
mingw32-make main
./main
```

Após testar o projeto, remova os arquivos gerados executando:

**Linux/macOS:**

```bash
make clean
```

**Windows:**

```bash
mingw32-make clean
```
